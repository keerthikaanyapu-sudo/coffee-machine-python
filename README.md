# Coffee Machine Project
A beginner Python project completed during the Udemy Python Bootcamp. This exercise helped me understand how to structure a small program using functions and data structures.

## Features
- Menu system for selecting drinks
- Resource checking (water, milk, coffee)
- Coin processing and payment validation
- Drink preparation simulation

## Key Skills Practised
- Functions and modular code
- Dictionaries for storing machine resources
- Conditional logic and control flow
- User input handling
- Basic debugging
